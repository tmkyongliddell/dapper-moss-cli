# dapper-moss-cli



给自己省点事的小工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/dapper-moss-cli.git
cd dapper-moss-cli
chmod +x run.sh
```

## 备注

就是给自己省点事，没做太多抽象。
